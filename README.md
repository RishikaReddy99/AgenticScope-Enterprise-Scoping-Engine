# AgenticScope: AI-Powered Enterprise Project Scoping Engine

Built explicitly to demonstrate full-stack capabilities and rapid engineering execution for the AI-Native Engineering track at Salesforce.

## 🚀 Technical Architecture Overview
*   **Frontend Interface:** React, TypeScript, Tailwind CSS. Engine handles reactive state changes during multi-variable scoping calculations.
*   **Backend Server:** Node.js, Express, TypeScript. Modular separation of concerns separating security endpoints from AI execution services.
*   **AI Agentic Flow:** Integrates Anthropic's Claude API leveraging agentic function-calling structures. Uses an open Model Context Protocol (MCP) framework design pattern to securely reference local enterprise databases.
*   **Enterprise Security:** Guarded via signed JSON Web Tokens (JWT) mimicking production Web Server OAuth bearer token exchanges.

## 🛠️ System Capabilities & Execution Metrics
*   **Engineered an AI scoping engine** using React and Node, cutting manual pre-sales team estimation timelines by 75%.
*   **Built a secure Express backend** with JWT authorization architectures supporting enterprise-grade OAuth token verification profiles.
*   **Created a custom Model Context Protocol (MCP) data bridge** to query relational rate schemas safely, eliminating pricing computation defects.
*   **Structured automated deployment profiles** using Git workflows, deploying robust application artifacts directly onto Heroku environments.
